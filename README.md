<!-- Provider registration added -->## About Laravel

<!-- Provider registration added -->

<!-- Provider registration added -->Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

<!-- Provider registration added -->

<!-- Provider registration added -->- [Simple, fast routing engine](https://laravel.com/docs/routing).

<!-- Provider registration added -->- [Powerful dependency injection container](https://laravel.com/docs/container).

<!-- Provider registration added -->- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.

<!-- Provider registration added -->- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).

<!-- Provider registration added -->- Database agnostic [schema migrations](https://laravel.com/docs/migrations).

<!-- Provider registration added -->- [Robust background job processing](https://laravel.com/docs/queues).

<!-- Provider registration added -->- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

<!-- Provider registration added -->

<!-- Provider registration added -->Laravel is accessible, powerful, and provides tools required for large, robust applications.
